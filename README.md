# Поток задач

MVP системы связанных рабочих конвейеров с пространствами, досками, задачами, план/факт-графиком и анализом рисков.

## Запуск

```bash
npm install
npm run db:push
npm run db:seed
npm run dev
```

После запуска зарегистрируйте первого пользователя через страницу `/register`.

## Проверки

```bash
npm test
npm run build
```

Данные хранятся в SQLite через Prisma. Схема оставляет путь для перехода на PostgreSQL: бизнес-логика не зависит от SQLite-специфичных запросов.
